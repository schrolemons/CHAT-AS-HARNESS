# skill：表情候选（sticker-pick）

## 它解决什么
模型面对一长串表情备注，容易反复发同一张，或者挑一张完全不搭的。
这个插件把「这轮哪几张最贴语境」先算好，只给 3 个候选，模型只需选或不选。

## 什么时候被调用
每轮唤醒拼提示词前（`beforePrompt`），且必须满足：
- 桥接这轮允许发表情（`stickerAllowed !== false`，即没被概率判成「本轮不带表情包」）；
- 有收藏表情可挑。

## 打分口径
- 语境关键词命中标签（吃/白饭/累/生气/夸/哭/告别/问号…）+3 左右；
- 「大肥鱼」本体系列 +1；
- 越久没发越靠前，用得太多轻微降权；
- 30 分钟内发过的重罚（-3）；
- 没备注的降权；
- **正事/情绪话题 → 直接劝退，不给候选。**

## 配置与状态
`config.limit`（候选数，默认 3）；最近一次候选写在 `state/plugins/sticker-pick.json` 的 `last`。

## 边界
只排序不发送；「发不发表情」仍由桥接概率决定，「发哪张」由模型从候选里选。
