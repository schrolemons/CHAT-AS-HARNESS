# skill：全局用户画像（profile-store）

## 它解决什么
让「谁是谁、聊过几次、喜欢什么、讨厌什么」跨会话有效，而不是每个会话各记一份、换个群就全忘。

## 什么时候被调用
- **收消息**（`onIncoming`）：记身份（userId/昵称）、出现过的会话、互动次数、最后出现时间。
- **拼提示词前**（`beforePrompt`）：产出【本会话用户画像（完整）】+【别处听来的（可分享）】两段。
- **被工具调用**：`profile_record_note` / `profile_record_facts` / `profile_snapshot`（走 `/api/plugins/call`）。

## 两层信息
| 层 | 内容 | 去哪 |
| --- | --- | --- |
| 完整 info | 身份、会话、次数、全部备注、结构化字段 | 只在本机 `state/user-profiles.json`；提示词里只给当前会话参与者看，且注明「别念出来」 |
| 可分享 info | 脱敏后的喜好/趣事/名言 | 可以出现在别的会话的「别处听来的」段落 |

脱敏规则：含 QQ/微信/电话/地址/密码/邮箱/身份证/银行卡等字样的、带 5 位以上数字的、联系方式形态的，一律不进可分享层。

## 边界
- 不判断「什么值得记」——那是 `profile-facts` 插件 + AI 的事。
- 不主动发消息；跨会话只分享可分享层，且禁止暴露来源。
- 桥接里不再保留第二份内存缓存：所有写入都走本插件，避免互相覆盖。
