# skill：浏览器管理（exec-browser-manager）

## 它解决什么
让 AI 能像人一样浏览/监测任意网站，同时**非必要不让人类重复登录**、安全可控、不被风控。
实际动作走 Playwright MCP（真实 Edge），这个插件管「怎么用」的口径。

## 规则
- 复用本机已登录会话（真实 Edge），不自动填账号密码，也不要求重新登录。
- 一次一页、慢一点；读结构（snapshot）优先于截图；不批量翻页/爬取。
- 禁支付/银行/身份验证；含身份证、银行卡、密码的页面不截图、不发内容。
- 遇到登录/验证码，停下来让用户自己在窗口手动完成。
- 节奏拟人：随机间隔、失败退避，避免触发风控。

## 什么时候被调用
- `beforePrompt`：当来信/唤醒原因里出现浏览器相关词时才注入规则（不每轮都塞）。
- 工具 `browser_policy`：只读查询规则（走 `/api/plugins/call`）。

## 后续：无头模式
同一套规则，后端可换成 headless 浏览器（保留独立 profile 以复用登录态），
实现「无人值守监测」；这是本层下一步要补的 `headless` 后端，规则不变。

## 边界
只声明规则与推荐，不自己执行浏览器操作；执行仍在 Playwright MCP，登录态只在本机、绝不上传。
