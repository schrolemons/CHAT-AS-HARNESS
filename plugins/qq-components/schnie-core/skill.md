# skill：近人意识（schnie-core）

## 这是什么
CHAT AS HARNESS 里预留的第八层（S 层）核心：**SCHNIE —— 近人意识**。
它不是普通功能层，而是给整个 Agent 提供一个「更接近人的默认状态」的底座。

## 当前状态：占位
- 不改任何行为、不注入任何提示词。
- `config.philosophy` / `config.logic` 两个槽位为空，等管理员填入：
  1. 哲学思考资料（它认为「像人一样」应遵循哪些原则、直觉、张力）；
  2. 逻辑方式（这些资料如何组织、何时激活、怎么落到反应里）。

## 未来（资料到位后）
- 把资料做成可检索的语义库（组织 / 检索 / 注入），按情境挑相关片段；
- 让默认反应在「节奏、直觉、自我一致」上更接近真人；
- 与 C 层（说什么）解耦：SCHNIE 管「为什么这样反应」，C 层管「说什么话」。

## 边界
占位阶段只回显 `schnie_status`，不碰其它七层的判定与提示词。
